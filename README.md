# Kanan Sweets 🍬 - Premium Luxury Sweet Shop, Bakery & Ice Cream Boutique

Welcome to the official web application repository for **Kanan Sweets** located at Lalat Janka Road, Madhakhali, Bhupatinagar, Purba Medinipur, West Bengal (721425).

## 🌟 Key Features

- **Luxury Aesthetic & Theme**: Custom Bengali crimson (`#D62828`), saffron terracotta (`#F4A261`), and gold (`#FFD166`) palette with dark mode support.
- **Digital Menu & Live Search**: Category filtering for Bengali Sweets, Custom Cakes, Ice Cream & Kulfi, and Gift Hampers with real-time text searching.
- **WhatsApp Pre-Order Engine**: Instant order builder for sweets, custom cakes, and event catering that formats and redirects directly to WhatsApp (`wa.me`).
- **Festival Countdown Timer**: 4-day ticking countdown banner for Durga Puja & Poila Boishakh pre-bookings.
- **Wedding Catering Showcase**: Customized Bengali Wedding Tattwa gift boxes, live sweet counters, and event quotation system.
- **Local SEO & Schema Markup**: JSON-LD Structured Data for `SweetShop`, `Bakery`, `IceCreamShop`, `LocalBusiness`, `FAQPage`, and `Product`.

## 📁 Repository Structure

```text
├── index.html       # HTML5 Semantic Code & Local Business Schema
├── styles.css       # Complete CSS Design Tokens, Responsive Layout & Dark Mode
├── script.js        # Dynamic Menu Engine, Lightbox, Pre-order Modal & WhatsApp Payload
└── images/          # Studio Food Photography Assets
```

## 🚀 How to Run Locally

Open `index.html` directly in any modern browser, or start a local HTTP server:

```bash
npx http-server -p 7000
```
Then visit `http://localhost:7000`.
